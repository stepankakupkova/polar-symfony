# Logger Implementation Plan

> **For agentic workers:** REQUIRED: Use the `subagent-driven-development` agent (recommended) or `executing-plans` agent to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementovat databázový logger identický s polar's LoggerPlugin — zapisuje do tabulky `application_log` stejná data ze všech controllerů, kde polar loguje.

**Architecture:** Jednoduchý `Logger` service (`App\Application\Service\Logger`) zapisuje přes `LogRepository` do tabulky `application_log`. API kopíruje polar: `notice(message, extra)`, `err(message, extra)`. Auto-doplňuje `datetime`, `uri`, `ip`, `session_id`, `reference`. Controllery ho dostávají přes constructor injection.

**Tech Stack:** PHP 8.5, Symfony 8, Doctrine DBAL, RequestStack

### Task 2: Create Logger Service

**Files:**
- Create: `src/Application/Service/Logger.php`

- [ ] **Step 1: Create Logger service**

Tabulka `application_log` má sloupce: `datetime`, `priority`, `message`, `description`, `user`, `reference`, `file`, `line`, `trace`, `xdebug`, `uri`, `ip`, `session_id`.

Logger automaticky doplní `datetime`, `uri`, `ip`, `session_id`, `reference`. Z controllerů se posílá `message` + `extra` pole s klíči `description`, `user`, `file`, `trace`, případně `line`.

```php
<?php

declare(strict_types=1);

namespace App\Application\Service;

use App\Application\Repository\LogRepository;
use Symfony\Component\HttpFoundation\RequestStack;

class Logger
{
	private const EMERG = 0;
	private const ALERT = 1;
	private const CRIT = 2;
	private const ERR = 3;
	private const WARN = 4;
	private const NOTICE = 5;
	private const INFO = 6;
	private const DEBUG = 7;

	private const PRIORITY_NAMES = [
		self::EMERG => 'EMERG',
		self::ALERT => 'ALERT',
		self::CRIT => 'CRIT',
		self::ERR => 'ERR',
		self::WARN => 'WARN',
		self::NOTICE => 'NOTICE',
		self::INFO => 'INFO',
		self::DEBUG => 'DEBUG',
	];

	public function __construct(
		private LogRepository $logRepository,
		private RequestStack $requestStack,
	) {}

	public function emerg(string $message, array $extra = []): void
	{
		$this->log(self::EMERG, $message, $extra);
	}

	public function alert(string $message, array $extra = []): void
	{
		$this->log(self::ALERT, $message, $extra);
	}

	public function crit(string $message, array $extra = []): void
	{
		$this->log(self::CRIT, $message, $extra);
	}

	public function err(string $message, array $extra = []): void
	{
		$this->log(self::ERR, $message, $extra);
	}

	public function warn(string $message, array $extra = []): void
	{
		$this->log(self::WARN, $message, $extra);
	}

	public function notice(string $message, array $extra = []): void
	{
		$this->log(self::NOTICE, $message, $extra);
	}

	public function info(string $message, array $extra = []): void
	{
		$this->log(self::INFO, $message, $extra);
	}

	public function debug(string $message, array $extra = []): void
	{
		$this->log(self::DEBUG, $message, $extra);
	}

	private function log(int $priority, string $message, array $extra): void
	{
		$request = $this->requestStack->getCurrentRequest();

		$reference = $extra['reference'] ?? $this->getErrorReference();

		$this->logRepository->insert([
			'datetime' => date('Y-m-d H:i:s'),
			'priority' => self::PRIORITY_NAMES[$priority],
			'message' => $message,
			'description' => $extra['description'] ?? null,
			'user' => $extra['user'] ?? null,
			'reference' => $reference,
			'file' => $extra['file'] ?? null,
			'line' => $extra['line'] ?? null,
			'trace' => $extra['trace'] ?? null,
			'xdebug' => $extra['xdebug'] ?? null,
			'uri' => $request?->getRequestUri(),
			'ip' => $request?->getClientIp(),
			'session_id' => $request?->hasSession() ? $request->getSession()->getId() : null,
		]);
	}

	private function getErrorReference(): string
	{
		$chars = md5(uniqid('', true));
		return substr($chars, 2, 2) . substr($chars, 12, 2) . substr($chars, 26, 2);
	}
}
```

## Poznámky k dalším modulům

Tyto controllery v polar-symfony zatím **nemají** write/admin akce odpovídající polar's logger calls:

| Modul | Polar-symfony stav | Logger se přidá |
|-------|-------------------|-----------------|
| Camera (admin) | Jen web `index()`, `detail()` | Až se migruje admin CRUD |
| Banner (admin) | Jen web `setShowed()` | Až se migruje admin CRUD |
| Program (admin) | Jen web `ShowController::index()` | Až se migruje admin CRUD |
| Authorization (signUp, resetPassword) | Jen `login()`, `logout()` | Až se migrují tyto funkce |
| News | Polar nemá logger v News | Nic |

Logger service je universální — každý budoucí controller ho jednoduše získá přes DI a zavolá `$this->logger->notice(...)` / `$this->logger->err(...)`.
